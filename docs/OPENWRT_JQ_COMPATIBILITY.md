# OpenWrt jq compatibility

The OpenWrt jq package can omit ONIGURUMA. A jq version number alone does not prove that `test`, `match`, `sub`, or `gsub` is available. Runtime normalization and classification use the basic jq operations available in that build.

The shared `cfip_jq_trim_filter` emits definitions for Unicode whitespace trimming. It preserves interior characters and non-whitespace controls, and uses codepoint indices with linear storage and work. Context generation emits sorted canonical JSON in one jq invocation. The fingerprint helper rejects a failed or empty context instead of hashing an empty string. Fourteen before/after context cases retain identical JSON bytes and hashes. Canonical ASCII source identifiers and operational reason/state markers use case-normalized substring checks; feature positions and schema files remain unchanged.

CFST observation parsing creates a private workspace and checks its initial JSON write, every row render and rename, and final atomic publication. Failures propagate even when the caller invokes the function in a conditional that disables Bash errexit. An existing output directory or symlink is refused. Known pre-publication failures preserve the previous output and clean the parser workspace. This does not claim power-loss durability, noncooperating-writer CAS, SIGKILL orphan recovery, quotas, or complete resource-exhaustion coverage.

`tests/jq-portable-runtime.sh` runs the existing context, operational-history, observation and Prefix/Colo tests with optional regex primitives denied; supported operations still invoke actual jq. It also checks Unicode whitespace examples and failed/empty fingerprint input. `tests/observation-write-faults.py` executes the actual parser with controlled write/tool faults. Native verification separately uses an isolated OpenWrt guest whose actual jq was compiled without regex support. Test payloads, probe/Runtime callbacks and files remain fixtures; this is not real proxy integration, an installed new-package acceptance result or physical-device proof.
