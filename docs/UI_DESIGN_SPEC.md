## 本仓最容易返工的三条

1. **A-1 优先使用 LuCI 核心和浏览器原生控件。** 原生基线来自 LuCI 核心组件、标准标记和浏览器默认控件，独立于所选主题。按钮、表单、表格、提示、模态框和保存栏优先复用这些实现。插件只为自身布局补充样式，避免重绘标准控件或依赖主题专属类与变量。切换主题时，若实际呈现发生变化，按 A-5 查明 CSS 来源并记录归因。

## 1. 归因原则：谁的问题谁修

**A-1 原生基线不随主题定制，主题偏差归主题。**「原生 LuCI / 浏览器控件和 `.cbi-page-actions` 等标准结构以不受主题专属覆盖的原生呈现为基线；不把当前主题皮肤当作原生样式，也不按主题名覆盖颜色、按钮尺寸、警告框、下拉框、模态框或原生工具栏。主题导致的偏差留作主题记录，插件不做主题专属补偿。」（goal L49）

**A-2 只有四类失败在插件内修：** 插件自有标记、自定义组件、插件 CSS、违反 LuCI 响应式标记契约。
混合问题时只修通用的插件组件行为。（goal L49）

**A-3 已裁决的具体案例（照此判，不重新讨论）：**

| 现象 | 判定 |
|---|---|
| Aurora 固定浮动工具条压住原生保存栏 | 主题 / LuCI 原生层（goal L115、L196、L210） |
| 浮动工具条展开时压住**插件自有**路径输入框 | 插件自有视图缺陷，只做条件化窄屏避让（goal L541–L542） |
| 窄屏页面宽 321px 而原生表单 323px | 主题 / LuCI 尺寸舍入，不加补偿 CSS（goal L275） |
| 原生页面导航容器 5px 横溢、菜单仍完整 | 主题 / LuCI 原生层（goal L213） |
| 徽标被主题 `text-transform` 成大写 | 主题渲染，不改插件、不改断言语义（goal L363） |

**A-4 避让规则不得按主题名写。** 条件必须是可观测的页面状态（如「窄屏 + 页面存在已展开的浮动
工具栏」），不能是 `body.theme-aurora …`。（goal L542）

**A-5 优先级冲突要落到 computed style。** 判定遮挡 / 覆盖前，先在浏览器读实际获胜规则与
`padding` 等最终值，不要凭选择器猜测。（goal L566–L570）

## 2. 布局与信息架构

**L-1 四段式（总览类页面）：** H2 标题 → 状态横幅（仅总览 / 服务健康页）→ 统计卡 2–4 个（仅总览）
→ 操作区 / 表格 / 表单分组 1–3 个 → 环境检测或只读 KV 表 → 页脚。

**L-2 列表页：** H2 → 工具栏按钮一行 → 表格 section（行操作在最后一列）→ 页脚。

**L-3 设置页：** H2 → 若干分组，每组 ≤6 行 → Save / Save & Apply / Reset → 页脚。

**L-4 普通用户优先的阅读顺序**（用户授权，goal L56）：先运行状态、安全状态、当前建议 / 测试 /
可执行操作及其影响；常见设置直达；高密度诊断（提供方、协议、内部 ID、原始契约、候选历史、
测量阈值）收进原生折叠详情或 Advanced 页。只有「确认无独立任务 + 已被更清晰信息替代 +
仍可从高级详情追溯」三者同时成立，才可隐藏内容。

**L-5 不得丢弃**：现有可用配置、必要安全状态、失败原因、回滚确认、高级用户查验数据。（goal L56）

**L-6 卡片密度与去重。** 重复标题、重复字段、空状态信息块、无效网格容器，先确认用户任务与
handler 再删；同一语义不得在两张卡里各说一次（goal L209 的四状态卡把 Rill 行从系统信息表移除即此例）。

**L-7 孤卡与语义重复。** 真实数据只产生一张卡时，不要留一整行空白；把相关小卡并入同一原生
section / grid（goal L311–L315）。

## 3. 操作归属（最容易返工的一条）

**O-1 按钮遵从真实操作对象与 LuCI 按钮语义。** 页面保存、区块动作、行内动作分放在各自的作用
范围里；「危险操作与高频刷新、筛选保持可辨识」。（goal L33）

**O-2 操作靠近对象。** 一个按钮必须能从它所在的行 / 区块直接看出它作用于什么；标题即对象，
说明即影响。（goal L55「操作靠近对象」+ L41「检查…操作归属」）

**O-3 按钮不裸奔。** 一排无标题的按钮不构成分组。原生写法二选一：
- JS 视图：`cbi-section` + `h3`（说明这组按钮作用于什么）+ `.ys-actions` 按钮组（UPNP/CFI 既有范式）；
- 表单 / 行式动作：每个动作一行 `cbi-value`，`cbi-value-title` 写对象，控件下方
  `cbi-value-description` 一句话说明「做什么、不碰什么」（CFI `form.Button` 既有范式）。

**O-4 危险区只留给不可逆操作**，左边框失败色；可恢复操作（清空日志等）不进危险区，但要二次确认。
（goal L33、CFI SPEC B-07/B-10）

**O-5 即时动作与待保存配置必须分开。** 页面上不得让用户分不清「这一下立刻生效」还是「要按保存」。
（goal L42、L33）

**O-6 动作标签整行不可拆。** 中文标签不得被拆成「部 / 署」这类单字换行；动作标签 `nowrap`，
不够宽就换行整个按钮。（goal L496、L204）

**O-7 默认操作栏。** 不得出现重复或无效的默认保存栏（`handleSave/Apply/Reset = null` 的只读页
必须真的不渲染）。（goal L20、L52）

## 4. 状态与文案

**S-1 状态用徽标，不用普通文本。** 运行 / 安装 / 新鲜度这类状态在表格里必须是徽标（主题
`.label` + 语义色），且「信息不能只靠颜色」。（goal L187、CFI SPEC B-06）

**S-2 一句一式。** 运行中：主语 + 在跑 + 作用；已停止：主语 + 未运行 + 下一步；空态：直接说
「没有是什么」；错误：发生了什么 + 数据是否还在 + 下一步。（CFI SPEC §2.5）

**S-3 不混用两套状态词**（「运行中 / Running / active」），不在同一界面重复表述同一结论。

**S-4 一级界面不出现内部实现细节**：RPC 方法名、字段名、契约键、内部 ID。（goal L56、SPEC §2.5）

**S-5 状态结论必须有依据。** 若显示「需要处理」，同页要能读到原因；否则会与「健康保护通过」
看起来矛盾。（goal L151–L152）

**S-6 短标签与完整标签并存。** 卡片里用短状态（`未部署`），详情里保留完整翻译，两者都要在
i18n 目录里。（goal L204）

## 5. 表格

**T-1 用原生 `.table`，不重设表头**（不大写、不加字距、不加底色）。（SPEC B-08）

**T-2 只加滚动容器**：`width:100%; overflow-x:auto`，表头 `nowrap`，单元格 `break-word`。

**T-3 窄屏转卡片行。** ≥6 列或带行操作的表在 1024px 转；≤4 列在 900px 转；600px 隐藏重复表头、
601px 恢复（CFI OpenClash 实例，goal L322）。

**T-4 行内操作要有自己的间距容器**：按钮之间 `0.5em` 量级、允许换行；不得让两个按钮边界重叠
（曾出现 1px 重叠被判粘连）。（goal L293–L294）

**T-5 移动端列表要紧凑**：不重复每个条目的字段标签、修改时间不折成多行、操作不竖向堆叠。
（goal L467 判 FAIL 的原始案例）

---

## 6. 表单

**F-1 用 LuCI CBI 表单**，分组用多个 `cbi-section`，每组短小（≤6 行）。

**F-2 标签、输入框、按钮的边框 / 高度 / 字重交给主题**；允许用 grid 做标签值对齐，不允许改
输入框圆角、最小高度、按钮字重与 hover 动效。（SPEC B-09、C-03）

**F-3 说明放控件下方，用 `cbi-value-description`（主题次要色），长度 1–2 行。**

**F-4 动态字段必须干净**：依赖项未选时整行隐藏（不渲染空行）；选中后标签、输入、说明分组
清楚，窄屏单列。（goal L161）

**F-5 校验交给原生**：越界用 LuCI 原生范围校验文案，不自造错误样式。（goal L278）

## 7. 间距与留白

**P-1 不追像素零差。**「状态区上下留白不要求像素完全相等；尽量复用 LuCI 原生样式，达到视觉上
大致均衡即可。以完整截图人工判断是否仍明显一边松、一边紧；DOM 测量只用于定位。」（goal L53）

**P-2 原生间距按跨主题基线，插件只修自身生成的布局。**「原生间距和标准结构以主题无关的 LuCI 基线为准；不得为了贴合某个主题的差异，在插件里添加主题专属间距或补偿 CSS，也不得破坏原生卡片、边框和排版。」（goal L52–L53）

**P-3 插件自有间距使用稳定基准刻度**（例如 `calc(0.25rem * n)` 或 `em`），不依赖当前主题的 `--spacing` 变量，也不用裸 px 魔数。

**P-4 零间距即缺陷。** 按钮贴着相邻字段 / 表格、卡片间 4px、控件视觉粘连，都按缺陷处理并给出
可测量的最小间距（历史修复取 7–24px 区间）。（goal L52、L188、L194、L299）

## 8. 响应式与断点

**R-1 常用宽度**：320、360、390、430、768、1024、1280、1440、1920。

**R-2 每个相关断点跑 `b−1 / b / b+1`**；已知边界：375、420、600、700、48rem(768)、1048、
1319/1320、431/432/433、1023/1024/1025。（goal L50）

**R-3 宽屏并列、窄屏堆叠。**「宽屏将可并列的相关控件同组排列，窄屏堆叠时保留明确的行距」，
且窄屏按原 DOM 与键盘顺序换行。（goal L33、L52）

**R-4 无页面级横滚、无控件被裁切或遮挡**；组件内部必要滚动可用。（goal L52）

**R-5 移动端主导航保持单行横向滚动**，不折成多行。（SPEC §4 裁决）

---

## 9. 主题与深色

**H-1 原生控件不重绘。** 原生控件保留 LuCI / 浏览器原生呈现；插件自有样式优先采用 LuCI 语义类，必要自定义时使用语义化颜色并保证明暗背景下可读，不写 `body.theme-*` 分支或仅适用于浅色的文本色。（goal L49、L228）

**H-2 不覆写通用 section 表面**：无阴影、无 >8px 圆角；不覆写表头、输入框、按钮外观。（SPEC §4）

**H-3 缓存键**：任何插件 CSS 变更必须同步递增 `?ui=…-vN` / `?v=@PKG_VERSION@`，否则浏览器继续
用旧样式。（四仓既有约定）

**H-4 主题对照（Vantage 等）只作归因探针**，不扩展正式六主题矩阵。（goal L49、L227）

## 10. 页脚

**X-1 四仓页脚结构一致**：品牌标记 + 项目 / GitHub / 云云云 chip 行；背景贴近文字与图标，
点击区仍足够大。（goal L54、L107）

**X-2 页脚几何以 PM 为参照对齐**，语言 / 主题 / 短视口下都要看。（goal L107–L108）

## 11. 可访问性与交互

**X-3 焦点可见、顺序正确、弹窗开关后焦点恢复、按钮真的可点、状态变更可感知。**（goal L52）

**X-4 选中态必须是原生选中类 + `aria-pressed` 同步**，不能只加一个无样式的 `active`。
（goal L246）

**X-5 保留可访问名称与版本 / 链接信息**，改结构不得让控件失去可读名称。（goal L35）

## 12. 证据与门禁（什么才算通过）

**E-1 门禁口径**：必测矩阵 = 主题模式 × 两语言 × 生效宽度及断点邻值 × 可见布局状态
（子页签、向导步骤、弹窗、展开行、依赖分支、加载 / 禁用、错误、空 / 有数据、长内容）。（goal L51）

**E-2 正式 UI 验收通过需要同时具备**：exact SHA 的 Actions 运行成功 + 产物 SHA-256 + 截图可打开 +
人工逐行审阅记录（PASS/FAIL/BLOCKED/N/A，N/A 附依据）+ 设备实机回看。自动门禁 PASS 不能替代
人工视觉复核。（goal L52、L57、L262）

**E-3 未终结的 job 一律不计为通过**；run 失败若发生在截图采集前，不能当 UI 失败，也不能当 PASS。
（goal L138、L198、L445、L466）

**E-4 同一 ref 不做并发重复 run**，会互相取消；重跑前先确认上一 run 终态。（goal L428、L445–L446）

**E-5 测试断言陈旧 ≠ 界面缺陷。** 先证明是断言与设计不符（例如默认折叠未挂载第二张表），
再修断言并保留首次报告。（goal L154）

**E-6 共享 CSS / 公共渲染器一改，所有消费页面重跑**，并在最终候选包上做全量验证。（goal L57）

**E-7 设备验收**：安装前后记录包 SHA、插件文件 SHA、UCI 配置 SHA、服务状态；只读复核，
有副作用的操作（A/B、保存、回滚、服务重启）放隔离实例。（goal L69–L70、L117–L118）

## 13. 判定清单（可否决项）

| ID | 判定 | 取证 |
|---|---|---|
| A-1 | 用自制控件替代已有原生实现，或插件样式重绘标准控件、依赖特定主题 | 视图标记、CSS 来源、浏览器计算样式 |
| A-2 | 为解决主题自身遮挡而改插件 CSS | diff + 归因说明 |
| L-4 | 一级界面上出现 RPC 名 / 契约键 / 内部 ID | grep 视图 + 截图 |
| O-2 | 按钮所在行看不出它作用于什么 | 截图 + DOM |
| O-3 | 一排无标题按钮充当分组 | DOM：`.ys-actions` 前无 `h3` / 无 `cbi-value-title` |
| O-6 | 中文动作标签被拆成单字换行 | 320px 截图 |
| O-7 | 只读页出现默认保存栏 | 截图 |
| S-1 | 表格状态是纯文本而非徽标 | DOM |
| T-1 | 表头被大写 / 加字距 / 加底色 | grep CSS |
| F-4 | 依赖未选时仍渲染空字段行 | 截图 |
| P-4 | 按钮与相邻字段零间距或视觉粘连 | 截图 + 测量 |
| R-4 | 出现页面级横向滚动或被裁切控件 | `scrollWidth > viewport` |
| H-1 | 写死颜色 / 浅色文本 | grep CSS |
| H-3 | 改了 CSS 没递增缓存键 | diff |
| E-2 | 只有自动门禁 PASS，没有人工审阅 / 实机 | 证据目录 |
