# 2.6.0-r8 Release Ready

状态：**候选版本 r8，发布动作未执行**。代码候选 `1ec2a6d`，PR #25（OPEN / MERGEABLE）；exact-SHA CI 全绿。Makefile `PKG_VERSION=2.6.0`、`PKG_RELEASE=8`，本文与源码版本一致。

## 变更摘要

- 错误提示统一为“人类可读标题 + 可展开/可复制技术详情”；raw error 不再直接暴露在 toast/错误态。
- 动态状态码映射为可读标签；未知值显示 `Unknown` / `Source error`，原始码进入可展开块，不再拼接 `Unknown (code)`。
- Sources 刷新不再整页 reload，保留未保存草稿；OpenClash 删除/恢复失败不再刷新成功态。
- Rill reset 成功后真实重载并反映状态；修复 `form.Button` 事件参数 `ev.currentTarget`。
- 合并 Overview 重复统计卡 CSS；深色配色只由 LuCI/Aurora `data-darkmode` 决定。
- legacy 自更新已停用（`AUTO_UPDATE=false`、`SELF_UPDATE_URL=""`，`--self-update` 返回失败）；Advanced 的弃用 `self_update_url` 不可编辑。
- uhttpd 改为可选依赖，仅 LAN Result Publisher 需要；nginx/lighttpd 系统不会被动安装第二套 Web 服务。
- i18n：516 keys（JS 507 + menu 9），POT/zh_Hans/en 各 552 条；动态映射与 raw-error 门禁接入 CI。
- 真实容器 LuCI UI 门禁继续覆盖草稿保护、RPC 错误、未知状态码与弃用字段只读。
- 源码版本 `2.6.0-r8`；未创建 tag/Release，未改 `release-channel.json`，未晋级 stable。
