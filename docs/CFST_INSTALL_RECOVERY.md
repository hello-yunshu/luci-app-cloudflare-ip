# CFST installation and recovery

The release download path checks its expected SHA-256 before parsing the downloaded archive. The installer also checks its supplied digest before listing or extracting the archive. A self-computed digest for a local legacy archive is a byte identity check, not independent publisher authentication; the existing legacy cache-bootstrap policy is unchanged.

The extracted candidate must pass an execution probe before installation. Version rendering and every preimage copy must succeed before the first live rename. Mutable binary, version, archive and metadata targets must be regular files or absent; an existing symlink or directory is refused. Preimages live in the private, uniquely allocated staging directory rather than fixed PID backup filenames.

The live replacements remain sequential per-file operations. On an in-process commit failure, existing artifacts are restored through fresh candidates; originally absent targets are removed. Original preimages are retained until every restoration succeeds. If any restoration fails, the operation returns failure, reports recovery as required and retains the named `old-binary`, `old-version`, `old-archive` and `old-metadata` files that existed before the attempt. The error includes their staging-directory path. Cleanup failure after a successful installation explicitly reports that installation occurred but staging cleanup failed.

This is in-process error recovery, not an atomic multi-file generation, a durable recovery journal, a concurrency guarantee against other installers, or proof of power-loss durability. Forced KILL/reboot recovery, orphan/retained-preimage storage limits and the full download/resource matrix remain OPEN. Existing unmarked backup files are not adopted or deleted by the new staging scheme.

`tests/cfst-install-faults.py` exercises the actual installer/downloader with private filesystem fixtures and injected command failures. It includes fresh/cached installation, snapshot and commit failures, restoration failure, invalid target paths, execution-probe failure and digest-before-parse checks. Its executable payloads are harmless shell fixtures, not genuine CFST binaries. On a host whose default Bash is too old for the production script, select a compatible interpreter with `CFIP_TEST_BASH=/path/to/bash python3 tests/cfst-install-faults.py`. Real CFST smoke, SDK package tests and device acceptance remain separate evidence.
