## Equivalence argument (why the measured bytes may stand for `30d6c31`)

1. `git ls-tree -r` over `package/luci-app-cloudflare-ip/root/` at both SHAs is
   **identical, no diff**. That tree contains the entire installed backend:
   `/etc/init.d/cf_ip`, `/etc/init.d/cf_ip_publisher`, `/usr/bin/cf-ip-auto*`,
   `/usr/libexec/cf-ip/*` (20 files), `/usr/libexec/rpcd/cf_ip`,
   `/usr/lib/lua/luci/controller/cloudflare-ip.lua`, menu/ACL/schema JSON.
2. Device-side `sha256sum` before and after installing `30d6c31` shows **all 31
   backend files unchanged** (e.g. `/etc/init.d/cf_ip`
   `72d26c8c…c090`, `/usr/bin/cf-ip-auto` `a7bc679b…27bb`,
   `/usr/libexec/rpcd/cf_ip` `b37cb2ce…359f`).
3. The only shipped differences are 4 frontend files
   (`cloudflare-ip.css`, `view/cloudflare-ip/overview.js`, `intelligence.js`,
   `settings.js`) and 3 translation catalogs (`en.po`, `zh_Hans.po`,
   `cloudflare-ip.pot`).
4. The soak harness measures backend behaviour only (ubus `cf_ip` status,
   mihomo process count, cron entries, error log counter, memory). It therefore
   observed exactly the same code as `30d6c31` for 12 hours.

## Boundary — stated plainly

- **Accepted:** 12-hour backend stability of the identical runtime tree, on the
  KVM DUT, with config preserved.
- **Not accepted by measurement:** the `30d6c31` frontend bytes were never
  exercised for 12 hours. The soak cannot test CSS/JS anyway; UI coverage comes
  from the separate LuCI UI Gate and visual evidence, not from this window.
- **Not accepted by measurement:** an exact-artifact 12-hour window on `30d6c31`
  or on the `2.6.0-r10` release artifact. The `30d6c31` window was terminated
  after **7 samples** at the user's direction (`soak-30d6c31-12h/README.md`),
  and no `SOAK_DONE` was written.
- **Classification:** “user-adjudicated equivalence acceptance”, not
  “exact-artifact 12 h pass”. Any external statement must use that wording.
- **Still BLOCKED / NOT RUN (unchanged):** PassWall real network, real power-cut
  drill, physical touch / soft keyboard / multi-finger gestures, OpenClash full
  backup/restore/delete matrix on device, aarch64 on physical hardware.
